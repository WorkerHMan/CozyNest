## 现象

产线上换了一批灯管，色温从 5000K 变成 6500K。原本红色物料的 H 值从 0 附近漂到 170 附近，阈值继续用就漏检。人眼几乎看不出灯光变了，因为大脑会自动校正。

## 先做一次灰卡校正

```python
# 用画面里的灰卡区域估计通道增益
patch = frame[y0:y1, x0:x1].reshape(-1, 3).mean(axis=0)
gain = patch.mean() / patch          # BGR 三个通道各一个增益
balanced = np.clip(frame * gain, 0, 255).astype(np.uint8)
```

如果场景里没有灰卡，退一步用「灰度世界」假设：整幅图的通道均值应该接近。这在物料占比不大的场景下够用，但背景有大量同色物体时会失效。

## 标定与阈值的关系

- 白平衡是标定的一部分，不是预处理的小技巧。它决定了同一颜色在不同光源下是否映射到同一数值。
- 做完白平衡再取阈值，然后把阈值和校正参数一起版本管理。只改阈值不改参数，问题会以更隐蔽的方式回来。
- 更稳的做法是换成与亮度、色温弱相关的特征（比如归一化 RGB 的比值），阈值区间会宽很多。

> 光变了，颜色就变了。任何只看像素数值的算法，都要先回答「这台相机的白点在哪」。
