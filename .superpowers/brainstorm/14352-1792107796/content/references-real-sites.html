真实的个人网站，挑几个你喜欢的

这些都是真人做的个人站，截图来自 personalsit.es（收录了 1145 个个人网站的真实截图），我逐个验过还活着。点卡片可以多选——选中的就是你想抄的方向，选完在对话里告诉我你选了哪几个。

老实说一句：这 8 个里我只逐页读过 rosano.ca，其余的是目录标签加真实截图，具体内容你点进去看更准。

rosano.ca · 加拿大 · 音乐人／写作者／开发者

最接近你想要的那个：blog（文章）+ vlog（影像）+ log（日志）+ Now 页 + sounds（音乐，下面还分"Vibrations / seeds / Aural"几张专辑页）+ lyrics（歌词）+ 开源项目 + wiki + webring + feed。一个人把"我做过什么"和"我是什么样的人"全塞进一个站，而且不显乱。

点进去重点看：它怎么把这么多入口排进一个首页，以及 /now 和 /sounds 长什么样。 打开 ↗

permanenttourist.ch · 标签：blog / film / photographer / travel / writer

"永远在路上的游客"——以照片和旅途见闻为主体，文章和影像混着走。

打开 ↗

craigmclachlan.co.uk · 标签：blog / css / designer / photographer

deliciousreverie.co.uk · 标签：books / developer · Benjamin Read

你要的"看过的书和电影"这一类记录，在个人站上通常长这样：不是豆瓣那种列表，是带短评的私人书架。
