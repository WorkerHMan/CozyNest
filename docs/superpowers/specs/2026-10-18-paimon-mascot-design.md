## 1. 这是什么，为什么

在 CozyNest 的每一页上，**右下偏中**的位置，长期站着一个小派蒙。它不是装饰图，而是一个**常驻的、活的、会被戳的**小东西：会呼吸、会眨眼、会跟着鼠标转头；被点一下会晃一下并冒一句撒娇的话。

**为什么**：站点所有者想要一个"有人气"的角落，把个人站从"一叠页面"变成"一个住处"。后续要扩成设置、更多互动，所以它必须是一个**可生长的小子系统**，而不是一次性贴图。

---

## 2. 目标 / 非目标 / 反目标

**目标**
- 第一版就能：站着、活着、被戳有反应、可开设置、刷新后记得。
- 零版权风险：**所有图形自己画**，不引入任何米哈游素材。
- 不干扰阅读与既有交互（音乐播放条、封面轮播键、木鱼光标、功德气泡）。

**非目标（第一版不做）**
- 不做 Live2D / 3D / 口型。
- 不做语音、音效（版权，见 §4）。
- 不做对话树、AI 聊天、好感度系统。
- 不做换装（但结构要留出换"皮肤"的口子）。

**反目标（做了就算失败）**
- 因为它的存在让页面在手机上出现横向滚动条。
- 切页面后出现两只派蒙 / 或它被重新挂载导致状态丢失。
- 它挡住音乐播放条或封面右下角的轮播暂停键。
- 在 `prefers-reduced-motion` 下依然晃动。
- 为了它引入一个几 MB 的运行时依赖。

## 4. 约束

### 4.1 版权（硬约束）

- 派蒙形象属米哈游。所有者选择**完全自己绘制**，因此本方案不涉及再分发官方素材，风险归零。
- **台词必须原创**，不得照抄游戏内对白原文。
- **不允许任何音频**：派蒙的配音是版权音频，"免费素材站"上的派蒙语音同样是未授权转载。此项不可协商。

### 4.2 平台约束

- Next.js 16（App Router，`cacheComponents: true`）＋ React 19 ＋ Tailwind 4。
- 该版 Next 在导航时用 `<Activity>` **隐藏而非卸载**页面。因此：
  - 派蒙必须挂在 **layout 层级**（与 `MeritCursor`、`MusicDock` 同级），不能挂在页面里；
  - **禁止命令式往 `document.body` 插 DOM**（旧式看板娘脚本的通行做法），必须纯 React 渲染，否则切页后会残留。
- 项目门禁：`tsc --noEmit`、`eslint`（0 warning）、`next build` 三者必须全绿。

### 4.3 设计系统

- **tokens 的唯一事实来源是 `src/app/globals.css`**。`design-system/cozynest/MASTER.md` 里的字体（IBM Plex Sans）与背景色已过时，**不要照它**。
- 必须遵守的 MASTER 规则：不用 emoji 当图标（用 Lucide SVG）、可点击元素有 `cursor-pointer`、焦点态可见、`prefers-reduced-motion` 生效、hover 不引起布局位移、正文对比度 ≥ 4.5:1。
- **头跟随鼠标**直接采用 MASTER 的 Complex 动效配方：`300–500ms`、`elastic.out(1,0.4)`、位移系数夹紧 `*0.3`、目标元素加 `will-change: transform`。
- MASTER 明确要求"magnetic 效果每屏不超过 1–2 个焦点元素"——派蒙是全站唯一的一个。

## 5. 行为规格

### 5.1 待机（无输入时）

| 动作 | 参数 |
|---|---|
| 呼吸（整体轻微上下 + 缩放） | 幅度 ≤ 2px / 1.5%，周期 3.6s，`ease-in-out infinite` |
| 眨眼 | 随机间隔 3–8s，单次 120ms（闭→开） |
| 呆毛晃动 | 周期 4.2s，幅度 ≤ 4°，相位与呼吸错开 |

### 5.2 头跟随指针

- 监听 `pointermove`（**单个稳定命名处理器**，便于清理）。
- 计算指针相对派蒙中心的偏移，乘 `0.3` 并**夹紧**到最大 ±6px 平移 / ±8° 旋转，作用在「头部组」上。
- 指针离开视口或组件不可见时，用 `elastic.out(1,0.4)` 回到中立位。
- 仅 `(pointer: fine)` 生效；触屏设备不做跟随。
- `prefers-reduced-motion: reduce` 时**完全关闭**跟随，保持中立位。

### 5.3 点击 = 被戳

一次点击触发以下全部，**互不阻塞**：

1. **晃一下**（核心）：整体做一次"被戳"的摆动 —— `rotate` 从 `0° → -6° → +5° → -3° → 0°`，总时长 **420ms**，`cubic-bezier(0.34, 1.56, 0.64, 1)`（带一点回弹）。
2. **表情**：眼睛从常态切到 `><`（闭眼笑）或眯眼，持续 900ms 后恢复。
3. **气泡**：在派蒙**左上方**冒一个对话气泡，显示一句随机台词，**2.8s 后淡出**（淡出 300ms）。

点击**不是**打开菜单，**不是**切换页面。齿轮（设置）是独立的小按钮，在气泡下方/派蒙左下角，与本体点击分开（避免"点一下就跳设置"的手感）。

### 5.4 台词

- 台词池放在 `src/config/paimon.ts`，中英各一份，**各 12 条**，风格：撒娇、卖萌、自夸、要吃的。
- 示例语气（写成原创，不抄游戏）：「欸嘿～再戳我就要生气啦（并没有）」、「派蒙可是你最好的伙伴哦！」
- **不允许连续两次抽到同一条**（复用站点里已用的"不与上次相同"策略）。
- **无障碍分两种气泡，不能混**：
  - **点击触发的**（用户主动）→ 容器是 `aria-live="polite"`，读屏会念。
  - **待机自发的**（见 §5.8，用户没动）→ 容器**不是** live 区域，只是普通文本节点。否则访客什么都不做，读屏也会被每 25–120 秒念一句，等同于骚扰。

### 5.5 拖动

- 长按（≥ 400ms）或按住拖动可移动位置；拖动结束后位置持久化。
- 拖动时禁止触发 5.3 的点击效果（用位移阈值 6px 区分"拖动"与"点击"）。
- 位置以**视口百分比**存储，保证换屏幕尺寸后仍在合理位置；并夹紧在安全区内，不允许拖出可视区。

### 5.8 待机自发说话

- 计时器每隔 **60s** 发一句（v1 不给用户调频率），**只在页面前台可见时计时**（`document.visibilityState`）。切到别的标签页就暂停，回来重新计时，不做补偿。
- 台词与点击共用同一个池子，同样不与上一条重复。
- 气泡是**非 live** 的普通文本（见 §5.4）。
- 用户点过一次之后才开始自发说话：没交互之前它**不该先开口**。

### 5.6 设置入口 —— 统一的「总设置」

**派蒙身上不挂自己的小齿轮。** 所有设置走一份**总设置**，右击派蒙打开（详见 §14）。v1 里这份面板**只有两项**，见 §14.2。

### 5.9 关闭态：淡手柄

当「显示派蒙」被关掉，**不要整个消失**，而是在原来的位置留一个**很淡的小手柄**：

- 形态：一个约 `44×44` 的圆角按钮，里面是一个极简的派蒙剪影图标（Lucide 规格的 SVG，不用位图），默认 `opacity: 0.28`，`hover`/`focus` 时升到 `0.65`。
- **点击 = 把派蒙叫回来**（即重新打开「显示派蒙」），不需要进设置。
- **右击 / 键盘的上下文菜单键（Shift+F10）= 打开总设置**，这样面板不依赖派蒙本体存在。
- 它不参与待机动画、不跟随指针、不冒台词、不产生功德气泡。
- 触屏：长按小手柄会触发 `contextmenu`，同样能打开总设置。

### 5.6b 派蒙自己的可选项（v1 只有一项）

| 项 | 是否进总设置 | 默认 |
|---|---|---|
| **显示派蒙** | ✅ **进** | 开 |
| 大小 / 台词频率 / 只在首页 / 重置位置 | ❌ **v1 不做**，值写死在配置里（中档、60s、不限首页），保留扩展位 | — |

> 所有者要求第一版只放轮播开关，所以这里只留"显示派蒙"——它是"关掉派蒙"这条需求的必需品，不给入口就关不掉。

### 5.7 移动端（< 768px）

- **收起态**：右下角 44×44 小圆钮，内是派蒙头像；点它**展开**。
- **展开态**：完整小人。展开后**点击本体 = 戳（晃一下 + 台词）**，与桌面一致。
- **收回**：展开时在派蒙右上角显示一个 44×44 的 × 按钮；点 × 收回。**点外部不收**（避免误触）。
- **收起态没有齿轮**；齿轮只存在于展开态。
- `collapsed` 是**纯运行时状态**，不进 localStorage —— 手机用户刷新后回到收起态，桌面用户永远展开。
- 不启用头跟随。

## 6. 视觉规格

- 画布：宽 `110px`（中档），内部用 `viewBox="0 0 120 160"` 的 **SVG**，纯矢量、无位图。
- 结构分组（便于分别驱动）：`body`、`head`（含 `hair`、`ahoge` 呆毛、`face`→`eyeL/eyeR/mouth`、`cloak` 星纹披风）、`shadow`（脚下椭圆阴影）。
- 配色自定，但与站点品牌协调：头发白偏冷（`#f7fbff` 系）、披风深蓝（`#25345c` 系）、星纹与发饰用品牌绿/青（`--brand` `--brand-2`）、眼睛蓝紫渐变。**不引入新的全局 token**（组件内部写死即可；这条只禁止动全局 `:root`）。
- **必须在浅色模式下也看得见**：站点默认就是浅色，`--background` 接近白，`#f7fbff` 的头发会直接消失。**决定：整只角色带深色描边（贴纸感）** —— 描边用 `#1b2440` 系、约 1.5–2px，头发内侧再压一道浅灰内阴影。这样同一套颜色在浅色/深色下都成立，不需要两套调色板。
- 气泡：`rounded-2xl` + `bg-background/95` + `border` + 小尖角；文字 `text-sm`、对比度 ≥ 4.5:1。

## 7. 无障碍

- 本体是一个 `<button>`，`aria-label` 为「戳一下派蒙」/「Poke Paimon」；键盘 Enter/Space 等价于点击。
- 齿轮按钮独立，`aria-label`「派蒙设置」，`aria-expanded` 反映 popover 状态。
- 焦点态可见（复用站点 `focus-visible:ring-*` 约定）。
- 气泡 `aria-live="polite"`；动画纯装饰，不承载信息。
- `prefers-reduced-motion: reduce`：关闭呼吸/呆毛/跟随/摆动，**但保留气泡文字**（反馈不能因为减少动态而消失，改为淡入淡出）。

## 8. 层级与避让

- `z-index`: **30**。必须低于 header（`z-50`）与 `MusicDock`（`z-40`），高于正文。
- 位置：`right` 贴边 `1rem`（移动端 `0.75rem`），垂直 `top: 62%`（可用设置微调）。
- **不得**与以下元素重叠：左下角音乐播放条（`bottom-4 left-4`）、封面右下角轮播暂停键（`right-4 bottom-5`）。派蒙在 62% 高度，两者都在底部 5rem 内，天然不冲突——实现后需目视确认。

## 9. 持久化

`localStorage` 单键：`cozynest:paimon`

```json
{
  "enabled": true,
  "size": "md",
  "frequency": "md",
  "homeOnly": false,
  "position": { "x": 92, "y": 62 }
}
```

（`collapsed` 故意不在里面，见 §5.7。）

- 读取失败（禁用/损坏/旧结构）必须**回退到默认值**，不得抛错。
- 服务端渲染时不得读 `localStorage`（会 hydration 不匹配）：首帧用默认值，客户端挂载后再应用已存设置。

## 10. 集成点

- 新组件挂在 `src/app/[locale]/layout.tsx`，与 `<MusicDock />`、`<MeritCursor />` 同级。
- 必须是 `"use client"`；如体量大，用 `next/dynamic` 懒加载（`ssr: false` 不允许在 Server Component 里直接写，需在客户端组件内使用或改用条件挂载）。
- `only-on-home` 判定复用 `MusicDock` 里已有的 `toPublicPath()` 逻辑（`usePathname` 预渲染期为 `/zh/...`，客户端为 `/...`）。它目前是 `music-dock.tsx` 的**模块内私有函数**，需要提升到 `src/lib/path.ts` 并让 `MusicDock` 一并改用 —— **不要复制两份**。
- **功德气泡要避让**：`MeritCursor` 在 window 上监听 `pointerdown`，戳派蒙也会触发，会在角色身上同时飘一个"+1"。**决定：戳派蒙不产生功德** —— 给派蒙根元素加 `data-paimon`，在 `MeritCursor` 的处理器里用 `closest('[data-paimon]')` 提前返回。这是对既有组件的 3 行改动，明确记录在此。
- 不新增依赖；图标用已装的 `lucide-react`；popover 用已装的 shadcn。

## 13. 已知风险

1. **视觉要靠人眼**：实施者无法在浏览器里看到成品，SVG 造型需要所有者多轮反馈（这是主要成本）。
2. **指针跟随可能产生重渲染**：应直接改 CSS 变量/`transform`，避免每帧 `setState`。
3. **`<Activity>` 交互**：切页时组件被隐藏；跟随指针的监听器在隐藏期间仍会收到事件，需要按可见性暂停，避免无谓计算。
4. **没有 GSAP**：MASTER 里那条头跟随配方用的是 GSAP 的 `elastic.out(1,0.4)`。项目未装 GSAP，**不为此引入依赖** —— 用 CSS `cubic-bezier` 近似回弹（例如 `cubic-bezier(0.34, 1.56, 0.64, 1)`），观感接近即可。
5. **全局降级已存在**：`globals.css` 已对全局强制 `animation-duration: 0.01ms !important`（reduced-motion），所以呼吸/眨眼/呆毛/摆动**会自动停**；只有 JS 侧的头跟随需要自己加 `matchMedia` 判断（照 `merit-cursor.tsx` 的写法）。

## 14. 总设置面板（右击派蒙打开）

### 14.1 形态

- **右击派蒙** → `contextmenu` 里 `preventDefault()` → 打开**右侧抽屉，占屏幕右半边**（`sm` 以下接近全屏）。
- 复用已有的 `Sheet`（`side="right"`，`w-full sm:w-1/2`），不新造抽屉组件。
- 改动**即时生效**，没有"保存"按钮。

### 14.2 分组与内容（v1：只有两项）

| 项 | 形式 | 默认 | 说明 |
|---|---|---|---|
| **轮播自动播放** | 开关 | 开 | 与封面右下角那个暂停键**同一份状态**，两处改一处，不能各记各的 |
| **显示派蒙** | 开关 | 开 | 关掉后变成 §5.9 的淡手柄 |

**推迟到以后（v1 不做，文档保留以便将来加）**：主题、语言、轮播间隔、音乐播放/音量、木鱼光标、功德气泡。

> 所有者明确要求第一版只放轮播开关，不要一次塞满。上面"推迟"那一行只是备忘，**v1 不实现**。

### 14.3 由此产生的改动（范围已缩小）

因为 v1 面板只有两项，**不需要大而全的设置系统**：

1. 一个小设置 store（`localStorage` + `useSyncExternalStore`），只存 `carouselAutoplay` 和 `paimon.enabled`（外加 §9 的派蒙位置/大小等）。
2. 一个总设置抽屉（复用 `Sheet`）。
3. **只把 `HomeBanner` 里的 `rotating` 提升到 store** —— 封面右下角的暂停键也必须读写同一份状态，否则会出现"抽屉说开、封面却停着"的鬼状态。
4. 派蒙本体 + 台词 + 待机/跟随/点击 + §5.9 的淡手柄。

音乐音量、光标开关**这次不动**。

### 14.4 可达性：不加页头齿轮

曾考虑在页头加一个齿轮作为第二入口，**已放弃**（所有者选择"原地留淡手柄"）。

替代方案（不加公共 UI）：

- 淡手柄本身是 `<button>`，可 Tab 聚焦、Enter 恢复派蒙；
